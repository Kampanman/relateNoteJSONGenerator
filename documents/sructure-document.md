# Relate Note JSON Generator

## 仕様説明書

---

## 使用する言語と条件

- html, css, javascript
  - 但しjavascriptはVanilla-jsを使用し、利用にネット接続を要するライブラリ（Jqueryなど）やフレームワーク（Reactなど）は利用しない

## 画面構成

```text
- 単一ページ。画面遷移はせず、そのためhtmlやパラメータは複数用いない。
- トップのサービスタイトルの下には、次の三種類のモード選択ボタンが配置されている
  - ノートデータ閲覧モード, ノートデータ新規作成モード, ノートデータ更新モード
    - 押下したボタンに応じて、このボタンエリアの下のエリアにコンテンツが表示される
- 以下のモード・フェーズごとに画面上の表示を分ける
  - ノートデータ新規作成モード
    - 基幹文登録フェーズ
    - 関連文登録フェーズ
    - ノートデータダウンロードフェーズ
```

---

```text
  - ノートデータ更新モード
    - JSONファイル読み込みフェーズ
    - 基幹文・関連文編集フェーズ
    - ノートデータダウンロードフェーズ
  - ノートデータ閲覧モード
    - JSONファイル読み込みフェーズ
    - 画面へのデータ反映フェーズ
```

## モード・フェーズの詳細

### ノートデータ新規作成モード

```text
- 基幹文登録フェーズ でのエリアコンテンツ
  - ノートタイトル入力欄
  - 基幹文入力欄
  - 「登録」ボタン
    - 押下すると「この内容でタイトルと基幹文を登録します。よろしいですか？」のメッセージダイアログが表示される
    - 「はい」を選択すると、関連文登録フェーズに移る
```

---

```text
- 関連文登録フェーズ でのエリアコンテンツ
  - 基幹文
    - 行ごとに、以下の要素が配置されている
      - 基幹文入力欄（編集可能）
      - 文の末尾に「＋」ボタン
      - ただし、その行が空白の場合は配置されない
      - 行の先頭（または末尾）に「[削]」ボタン。押下するとその基幹文と紐づく関連文を一括削除する
    - 基幹文の行間に「＋ ここに基幹文を追加」ボタンが配置されている
      - 押下すると、その位置に新しい基幹文入力行を挿入する
    - 「＋」を押下すると表示されるもの
      - 関連文入力欄
      - 関連文入力欄横の「＋」「ー」ボタン
        - その入力欄に何か入力されている状態で「＋」を押下すると、その入力欄の下に関連文入力欄と「＋」「ー」ボタンを追加配置する
        - 「ー」は2つ目以降の関連文入力欄右横に配置される
          - 押下するとその入力欄・「＋」「ー」ボタンと、それ以降の追加したそれらを削除する
      - 「基幹文に関連付ける」ボタン
        - 押下すると「基幹分に関連付けてよろしいですか？」のメッセージダイアログが表示される
        - 「はい」を選択すると、「＋」ボタンで設けてきた入力欄の入力内容の分、関連文が基幹文に紐付けられる
          - JSONファイルでどのように設定されるかは、「## JSONでのオブジェクト構成」で記述
        - 関連文が紐付けられたら、その基幹文に紐づく関連文の入力欄等一式が閉じられる
    - 「＋」は押下すると「ー」になる
      - 「ー」を押下すると、その基幹文に紐づく関連文入力欄の一式が閉じられ、ボタンは「＋」に戻る
```

---

```text
    - 基幹文の最終行下の「データをJSON化する」ボタン
      - 押下すると表示されている基幹文・関連文のエリアが非表示になる
      - これによりノートデータダウンロードフェーズに移行する
  - 関連文
    - 基幹文の該当行と関連する内容を入力する。追加もできる
- ノートデータダウンロードフェーズ
  - エリアには次の部品が表示される
    - ノートタイトル, 基幹文行数, 関連文を登録した基幹文の行数
    - 「JSONをダウンロード」ボタン
  - 「JSONをダウンロード」を押下すると、登録したノートデータのJSONファイルをダウンロードできる
    - JSONファイルの構成については、「## JSONでのオブジェクト構成」で記述

### ノートデータ更新モード
- JSONファイル読み込みフェーズ でのエリアコンテンツ
  - ドラッグアンドドロップエリア
    - （JSONファイルがドラッグアンドドロップされた後）「このファイルを読み込む」ボタン
      - 押下すると 基幹文・関連文編集フェーズ に移行する
- 基幹文・関連文編集フェーズ でのエリアコンテンツ
  - 基本的な機能は、「### ノートデータ新規作成モード」の 関連文登録フェーズ と共通。
  - 読み込んだJSONの「基幹文」および「関連文」がそれぞれの入力欄に初期値として反映される。
  - 読み込み後も「[削]」ボタンによる行削除や「＋ ここに基幹文を追加」による行挿入が可能。
- ノートデータダウンロードフェーズ
  - これも「### ノートデータ新規作成モード」のものと同様の機能である
```

---

### ノートデータ閲覧モード

```text
- JSONファイル読み込みフェーズ でのエリアコンテンツ
  - ドラッグアンドドロップエリア
    - （JSONファイルがドラッグアンドドロップされた後）「このファイルを読み込む」ボタン
      - 押下すると ノートデータ反映フェーズ に移行する
- ノートデータ反映フェーズ でのエリアコンテンツ
  - 空白行も含めて、登録したノートの基幹文がページのエリア内に表示される
    - 関連文を設定している行は、文末に「＋」マークのボタンが設置される
      - 「＋」は押下すると「ー」になる
        - 「ー」を押下すると、その関連文集の表示箇所は閉じられる
      - 「＋」を押下すると、その基幹文に紐付けた関連文が表示される
        - 関連文が複数ある場合、関連文の末尾にも「＋」ボタンが設置される
          - この「＋」ボタンを押下すると、次の関連文（この基幹文に紐づくもの）が表示される
```

---

### 全モードに共通して設置するもの

- どのモードの場合も、画面には次のものを表示する
  - トップのサービスタイトル
  - 次の3種類のボタン
    - ノートデータ閲覧モード
    - ノートデータ新規作成モード
    - ノートデータ更新モード
  - 画面右下に固定する「⇑」ボタン（押下すると画面トップに戻る）

## JSONでのオブジェクト構成

- JSONファイルのオブジェクトは、主に次のような構成になる

```text
{
  "title":"(ノートタイトル入力欄で入力した内容)", 
  "created": "(新規登録された日時)", 
  "contents": [
    { "main": "(基幹文)", "relate": [] },
    { "main": "(基幹文)", "relate": [
      { "text": "(関連文)" },
      { "text": "(関連文)" },
      { "text": "(関連文)" },
    ] },
    { "main": "(基幹文)", "relate": [
      { "text": "(関連文)" },
    ] },
  ]
}
```
