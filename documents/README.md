# Relate Note JSON Generator

## 概要

**Relate Note JSON Generator** は、基幹となる文章と、それに関連する複数の文章を効率的に管理し、構造化されたJSONファイルとして生成・編集・閲覧するためのWebアプリケーションです。

このツールは、クライアントサイドのJavaScriptのみで動作し、サーバーを必要としません。すべてのデータ処理はブラウザ内で完結するため、手軽かつ安全に利用できます。

## 主な機能

- **ノートデータ新規作成モード**:
  - ノートのタイトルと、改行で区切られた複数の基幹文を登録できます。
  - 各基幹文に対して、複数の関連文を動的に追加・削除できます。
  - 作成したデータ構造をJSONファイルとしてダウンロードできます。

- **ノートデータ更新モード**:
  - 既存のJSONファイルをドラッグ＆ドロップまたはファイル選択で読み込めます。
  - 読み込んだデータ（主に関連文）を編集し、更新内容を保存した新しいJSONファイルをダウンロードできます。

- **ノートデータ閲覧モード**:
  - JSONファイルを読み込み、その内容を整形された見やすい形式で閲覧できます。
  - 各基幹文に紐づく関連文は、トグルボタンで表示・非表示を切り替えられます。

## 使用方法

1. `app.html` をブラウザで開きます。
2. 画面上部のボタンから、実行したいモードを選択します。

### ノートデータ新規作成モード

1. 「ノートデータ新規作成モード」ボタンをクリックします。
2. 「ノートタイトル」と「基幹文」を入力します。基幹文は改行することで複数登録できます。
3. 「登録」ボタンをクリックします。
4. 登録した各基幹文の右側にある「＋」ボタンをクリックすると、関連文の入力欄が表示されます。
5. 関連文を入力し、「基幹文に関連付ける」ボタンで保存します。
6. すべての編集が終わったら、画面下部の「データをJSON化する」ボタンをクリックします。
7. 内容を確認し、「JSONをダウンロード」ボタンでファイルを保存します。

### ノートデータ更新モード

1. 「ノートデータ更新モード」ボタンをクリックします。
2. 編集したいJSONファイルをドラッグ＆ドロップするか、エリアをクリックしてファイルを選択します。
3. 「このファイルを読み込む」ボタンをクリックします。
4. 新規作成モードと同様のインターフェースで、関連文の追加・編集・削除を行います。
5. 編集後、「データをJSON化する」→「JSONをダウンロード」の手順でファイルを保存します。

### ノートデータ閲覧モード

1. 「ノートデータ閲覧モード」ボタンをクリックします。
2. 閲覧したいJSONファイルを読み込みます。
3. データが整形されて表示されます。基幹文の右にある「＋」/「ー」ボタンで関連文の表示を切り替えられます。

## コマンドラインツール (Python)

`generators`フォルダには、ファイル形式の変換などを行うためのPythonスクリプトが格納されています。
これらのツールを利用するには、お使いのコンピュータでPythonを実行できる環境を準備する必要があります。

### 1. Pythonの環境構築

スクリプトの実行には **Python 3.6** 以上が必要です。OSごとに以下の手順でインストールしてください。

#### Windows

1.  Python公式サイトのダウンロードページにアクセスします。
2.  インストーラーをダウンロードして実行します。
3.  インストーラーの最初の画面で、**「Add Python to PATH」**（または「Add python.exe to Path」）のチェックボックスを**必ずオン**にしてから、「Install Now」をクリックしてインストールを進めてください。

#### macOS

1.  ターミナル（Terminal.app）を開きます。
2.  Homebrewがインストールされていない場合は、まずHomebrewをインストールします。
3.  以下のコマンドを実行してPython 3をインストールします。
    ```bash
    brew install python
    ```

#### Ubuntu / Linux

1.  ターミナルを開きます。
2.  以下のコマンドを実行して、Python 3と関連パッケージをインストールします。
    ```bash
    sudo apt update
    sudo apt install python3 python3-pip
    ```

### 2. スクリプトの実行方法

環境構築後、以下の手順でスクリプトを実行できます。

1.  **ターミナルを開く**:
    -   **Windows**: `コマンドプロンプト` または `PowerShell` を起動します。
    -   **macOS/Ubuntu**: `ターミナル` を起動します。

2.  **プロジェクトフォルダへ移動**:
    `cd`コマンドを使用して、このプロジェクトのルートフォルダ（`app.html`などがある場所）に移動します。
    ```bash
    # 例: デスクトップ上のプロジェクトフォルダに移動する場合
    cd Desktop/relateNoteJSONGenerator
    ```

3.  **スクリプトを実行**:
    `python`（または`python3`）コマンドに続けて、実行したいスクリプトのパスと必要な引数を指定します。
    ```bash
    # 例: generatorsフォルダ内の a_script.py を実行する場合
    python generators/a_script.py [引数1] [引数2] ...
    ```
    *macOSやUbuntuでは、`python`の代わりに`python3`コマンドを使用する必要がある場合があります。*

```json
{
  "title": "あなたのノートタイトル",
  "created": "20XX-XX-27TXX:00:00.000Z",
  "contents": [
    {
      "main": "これが一つ目の基幹文です。",
      "relate": [
        { "text": "一つ目の基幹文に関連する文章Aです。" },
        { "text": "一つ目の基幹文に関連する文章Bです。" }
      ]
    },
    {
      "main": "これが二つ目の基幹文です。",
      "relate": []
    }
  ]
}
